StudyDesk — 3rd Year B.Tech AIDS

Personal academic planner and study management system.

Open index.html to start the project.

Pages:
index.html       Dashboard
tasks.html       Tasks
schedule.html    Subject-wise Schedule
exams.html       Exam Tracker
calendar.html    Calendar
stats.html       Study Statistics

Frontend:
HTML
CSS
JavaScript

Backend:
Node.js
Express.js

Database:
MySQL
Database Name: studydesk_aids

Database Tables:
subjects
tasks
exams

Architecture:
Frontend → JavaScript Fetch API → Node.js/Express Backend → MySQL

Subjects:
FLA — Formal Language and Automata Theory
CG — Computer Graphics
SE — Software Engineering
OOPS — Object-Oriented Programming Language
DAA — Design and Analysis of Algorithms
SC — Soft Computing
PM — Predictive Modelling (IBM)
CL — Constitution of India

Important:
The frontend communicates with the backend through:
http://localhost:5001

The backend connects to the MySQL database:
studydesk_aids

Tasks and exams are stored permanently in MySQL.
